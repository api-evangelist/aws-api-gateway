Today, AWS is introducing Synchronous Express Workflows for AWS Step Functions. This is a new way to run Express Workflows to orchestrate AWS services at high-throughput. Developers have been using asynchronous Express Workflows since December 2019 for workloads that require higher event rates and shorter durations.
